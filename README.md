# rpi-hello

The smallest useful [rpi](https://github.com/bigfish1913/pi-rust) extension: it
registers one tool and one slash command.

| Capability | Name | What it does |
| --- | --- | --- |
| Tool | `hello` | `{ "name": "Ada", "excited": true }` → `Hello, Ada!!!` |
| Command | `/hello` | `/hello Ada --excited` → same greeting, no model round-trip |

The extension exists as a reference for the rpi plugin ABI (tool lifecycle,
prompt metadata, slash command) and as an end-to-end test of the prebuilt
distribution protocol.

## Install

Prebuilt (no Rust toolchain needed):

```bash
rpi install rpi-hello --github bigfish1913/rpi-hello
```

From source:

```bash
rpi install --path . --force
# or, while iterating:
rpi dev
```

Restart `rpi` after installing. The tool shows up in the system prompt:

```bash
rpi --no-session --debug-system-prompt -p x | grep 'hello'
```

## Usage

Ask the model for a greeting and it calls the tool:

```text
> say hello to Ada
```

Or use the command directly (no model call):

```text
/hello Ada
/hello Ada Lovelace --excited
```

## Permissions and side effects

* **Network:** none. The extension never opens a socket.
* **Filesystem:** none. It does not read or write files.
* **Persistence:** none beyond rpi's own installation registry.
* **Secrets:** none read, none required.

## Uninstall

```bash
rpi uninstall rpi-hello
```

## Development

```bash
cargo fmt --check
cargo test --locked
cargo clippy --locked --all-targets --no-deps -- -D warnings
```

Release assets are built by `.github/workflows/release.yml`; each target gets
an archive plus a `rpi-extension.json` manifest, generated by
`scripts/package.py`. Publishing a `rpi-hello-v<version>` tag is the only
release step.
